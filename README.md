# The Long Roast: Lawmakers and the File They Cannot Convert

One satirical sentence about lawmakers who would regulate AI, crypto, or the internet — but cannot convert a file to PDF.

> Congress can draft a 400-page bill to govern artificial intelligence, yet still emails its staff asking how to turn that very bill into a PDF.

## Why it fits the judge's brief

- **Bite with a real turn:** the setup grants Congress enormous authority (a 400-page bill governing AI), then undercuts it with the smallest possible failure — the authors cannot convert the very bill they wrote.
- **Aim stays on power:** the joke is about lawmakers and the rules they write, not random abuse; the incompetence is legislative, not personal.
- **Specific, not cliché:** no generic "old man yells at cloud" tech-illiteracy gag — the detail is concrete (a 400-page bill, an email begging staff for help) and the irony is structural: the regulator cannot operate the artifact it regulates.
- **Punch on the last words:** the sentence reads clean in one pass and lands on "into a PDF" — the file format itself is the punchline.
- **One sentence, 142 characters** — inside the 1–320 gate, no explanation needed. It stands alone: no setup, no footnote, no second sentence to rescue it.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

`main.py` (pure Python stdlib) reads `entry.txt`, validates the gate (1–320 characters, not only whitespace), and writes it byte-identical to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
